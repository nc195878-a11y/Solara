# ☀️ Solara

### A calmer way to understand yourself.

**Solara** is an AI wellness companion designed to help you check in with yourself, talk through your day, reflect, and notice patterns over time — without pretending to be a therapist.

🌐 **Live:** https://solara-journey.vercel.app/

---

## ✨ What Solara Does

Solara turns self-reflection into a simple daily loop:

**1. Check in**
Choose your mood, add a few context tags, and share what's on your mind.

**2. Talk**
Have a reflective AI conversation that already understands your check-in.

**3. Reflect**
Get three guided journal prompts and optionally write your own reflection.

**4. Understand**
See gentle observations about recurring patterns and trends — never diagnoses.

**5. One small step**
End each conversation with something simple and actionable.

---

## 🧠 Core Features

* 💬 Context-aware AI conversations

## 🚀 Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/solara.git
cd solara
npm install
npm run dev
```

Create a `.env` file with your required Supabase and AI credentials, then open:

```text
http://localhost:5173
```
